# Oracle JET 10 module

This folder pins Oracle JET **10.0.0** and contains a dashboard view-model that consumes the Spring Boot JSON API. Generate an Oracle JET 10 application with the Oracle JET CLI, copy `src/js/alm-dashboard.js` into its view-models folder, and bind it to `oj-table` and `oj-form-layout` components. The server's built-in static UI remains immediately runnable without an npm build step.
